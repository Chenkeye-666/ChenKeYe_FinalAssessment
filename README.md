# RDC 社区 - 类社交 APP 移动端核心网页开发

## 1. 项目简介

本项目是一个基于 **HTML + CSS + 原生 JavaScript** 实现的移动端类社交社区网页项目，主要面向移动端页面开发考核。项目采用单页应用结构，通过 Hash 路由切换不同页面，配合后端接口完成登录、帖子浏览、发布、评论、搜索、消息通知、私聊、个人主页等核心社交功能。

项目没有使用 Vue、React、Webpack、Vite 或第三方 UI 组件库，整体以原生前端能力实现页面结构、样式、交互和接口请求。

## 2. 技术栈

- HTML5：页面结构与语义化布局
- CSS3：移动端布局、响应式适配、动画、弹窗、瀑布流样式
- 原生 JavaScript：DOM 操作、事件绑定、状态管理、Hash 路由
- Fetch API：后端接口请求
- WebSocket：私聊消息连接
- LocalStorage / SessionStorage：登录状态、历史账号、草稿、消息已读、本地私聊交互状态等

可以直接用浏览器打开：

```text
index.html
```

### 方式二：使用本地静态服务器

推荐使用 VS Code 的 Live Server，或使用任意本地静态服务器运行项目。

例如：

```bash
npx serve .
```

然后访问命令行提示的本地地址。

## 7. 接口说明

接口基础地址在 `js/config-state.js` 中配置：

```js

```

私聊 WebSocket 地址在 `js/chat.js` 中使用：

```js
wss://duck1437.shop/ws/chat?token=...
```

## 8. 本地存储说明

项目中使用 `localStorage` 和 `sessionStorage` 保存部分前端状态，包括：

- token 和 userId
- 当前标签页登录标识
- 记住密码和历史账号
- 评论草稿
- 发布页自动草稿
- 帖子收藏状态缓存
- 消息已读状态
- 私聊置顶、删除和撤回状态

其中消息已读、私聊置顶、删除和撤回属于前端本地交互状态，换浏览器或清除缓存后不会同步。

## 9. 已做的稳定性处理

- 首页上拉加载使用时间间隔限制和加载状态锁，避免重复请求
- 帖子点赞、收藏按钮使用状态同步，避免操作后页面状态不一致
- 动态渲染按钮使用 `dataset` 标记，避免重复绑定事件
- 消息未读轮询使用状态锁，避免并发请求
- 图片加载后再插入瀑布流，减少布局错位
- 页面切换时保存部分滚动位置和草稿内容
- 评论数量根据评论列表同步刷新
- 详情页旧请求返回时尽量避免影响当前页面

## 10. 注意事项

1. 本项目为移动端页面，支持在浏览器移动端尺寸或手机端预览。
2. 后端接口需要可访问，否则登录、帖子、评论、消息、私聊等接口相关功能无法正常使用。
3. 消息如果帖子被删除，前端无法准确推导原帖，只能做避免错误跳转。
4. 消息已读状态目前是本地实现，不能跨浏览器同步。
5. 私聊置顶、删除、撤回为本地交互效果，不会改变服务端数据。

## 11. 项目特点

- 未使用前端框架，符合原生前端考核要求
- 页面拆分为多个功能模块，便于维护
- 移动端布局完整，包含底部导航、弹窗、瀑布流、卡片列表等常见移动端交互
- 覆盖帖子、评论、用户、消息、私聊等社交类核心功能
- 使用原生 WebSocket 完成私聊通信
- 使用本地存储增强用户体验
